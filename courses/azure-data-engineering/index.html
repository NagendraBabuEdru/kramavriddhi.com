Azure Data Engineering Course: Basic to Advanced

A free course that takes you from zero to job-ready Azure data engineer in three levels and about 110 videos. Every module adds a piece to one retail project, so you finish with a real portfolio.

Watch on YouTube: youtube.com/@kramavriddhi
Videos are released level by level. Subscribe to get each new lesson.

Before you start

  • Basic: comfortable with a computer and Excel. No cloud or coding needed.
  • Intermediate: SQL joins and grouping, basic Python, or the Basic level.
  • Advanced: a year of hands-on pipelines, Spark and Git basics.

You need an Azure free account or pay-as-you-go subscription with a budget alert, a Microsoft Fabric trial, Databricks (Free Edition is fine for practice), VS Code, Git and Python 3.11 or newer.

Watch your Azure bill. Labs create paid resources. Set a budget alert first and delete resources after each lab; most learners spend about $10 to $20 a month this way.

For: Freshers, career switchers, and BI or SQL people new to the cloud. Time: about 6 weeks, 8 modules, about 35 videos. Exam: DP-900 (Azure Data Fundamentals).
