Fix the Playbook

An Ansible playbook is a YAML file that tells servers what to do. Someone broke this one. Put the lines in order, fix the indentation, and press Run.

    site.ymlTap a line, then use the buttons

      Each dot is one space. Indent and Outdent move a line by 2 spaces. You can also drag the dotted handle: up and down to move, left and right to indent. Keyboard: Shift + arrow keys move a line, Left and Right change the indent.

      How to play

      • Tap a line to select it. Then use Up and Down to move it and Indent and Outdent to change its spaces.
      • Press Run playbook. If something is wrong, the terminal shows an error like real Ansible would, and a yellow box explains the fix in simple words.
      • Stars: right first time is 3 stars, one failed run is 2 stars, more is 1 star.
      • YAML rules: spaces only (never tabs), 2 spaces per level here, and a line that ends with a colon holds the lines indented under it.

      The terminal is a simulation for learning. The playbooks themselves are real, correct Ansible you can run on Ubuntu or Debian servers in an inventory group called web.
