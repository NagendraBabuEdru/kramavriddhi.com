Build the Data Pipeline

Data has a journey: it is collected, stored, cleaned and shown. Put the Azure services in the order the data travels, then press Run and watch it flow.

    Your pipelineData flows from step 1 to the last step
      BlocksTap a block, then tap a step. Or drag it.

      How to play

      • Tap a block, then tap an empty step to put it there. Tap a filled step to send its block back.
      • Drag works too, on a phone or with a mouse. With a keyboard, use Tab and Enter.
      • When all steps are full, press Run the pipeline. Correct steps get a tick; wrong blocks go back.
      • Stars: right first time is 3 stars, one wrong run is 2 stars, more is 1 star. Some levels have a block that does not belong at all.

      Real projects can use other services too (for example Microsoft Fabric). These levels show common, correct patterns, not the only ones.
