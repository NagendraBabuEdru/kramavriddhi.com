# YouTube playlists for Kramavriddhi

Create each one in **YouTube Studio → Content → Playlists → New playlist**.
Set **Visibility: Public**. Copy the **Title** and **Description** below.

Then add them to your channel home page:
**Customize channel → Layout → Add section → Single playlist**, in this order:
1. Latest Updates & Deadlines
2. Farmers Schemes
3. Schemes for Girls & Women
4. Jobs, Internships & Skills
5. Our Apps & Games

A video can be added to more than one playlist.

## Video titles: a pattern that works

`[Big number or question in Telugu] | [Scheme name in English] [year]`

Examples:
- `అమ్మాయిలకు ₹50,000 స్కాలర్‌షిప్! | Pragati Scholarship 2026 Last Date`
- `పీఎం కిసాన్ 24వ విడత ఎప్పుడు? | PM Kisan 24th Installment Date`
- `మీకు ఏ పథకాలు వస్తాయి? 1 నిమిషంలో చెక్ చేయండి | Scheme Eligibility Checker`

Always put the matching **kramavriddhi.com** guide link in the first line of the video description and in a **pinned comment**.
