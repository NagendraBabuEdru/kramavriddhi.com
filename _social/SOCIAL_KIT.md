## 1. Create the accounts (you do this, about 5 minutes each)

**Use the same Google account (nagendradev650@gmail.com) for YouTube.** For Instagram, use support@kramavriddhi.com or your phone number.

### YouTube channel
1. Open youtube.com → profile icon → **Create a channel**.
2. Choose **"Use a custom name"** → name: **Kramavriddhi**.
3. Handle: **@kramavriddhi** (or @kramavriddhi_telugu if taken).
4. Upload `profile-picture.png` and `youtube-banner.png`.
5. Paste the description below, and add the link **https://kramavriddhi.com**.

### Instagram account
1. Install Instagram → **Create new account**.
2. Username: **kramavriddhi** (or kramavriddhi.telugu / kramavriddhi_in).
3. Name: **Kramavriddhi | Govt Schemes** (the name field is searchable, so the keywords help).
4. Profile photo: `profile-picture.png`.
5. Switch to a **Professional account → Creator → Category "Education"** (free, and it gives you visitor stats).
6. Paste the bio below and add the link **kramavriddhi.com**.

When done, tell Claude the handles, and they will be added to the website footer.

## 5. Posting routine (15 minutes a day)

- **Every new update on the website → 1 Instagram post + 1 YouTube Short.**
- Best times: **7–9 AM** and **7–10 PM**.
- Always: big number or date first, Telugu first, link in bio, "share with your family."
- **Safety rule:** never ask followers for Aadhaar, OTP or money, and always tell them to apply only on official portals. This builds trust.
- Reply to comments with the relevant guide link from kramavriddhi.com.
